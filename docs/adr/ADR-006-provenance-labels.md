# ADR-006: Provenance labelling as a UI contract
Status: accepted

Every data element renders one of: LIVE_API, CACHED_LIVE_DATA, DEMO_FIXTURE,
UPLOADED_DOCUMENT, SIMULATED_OUTCOME, PUBLIC_FACT, REPRESENTATIVE_DEMO_STANDARD.
The Portfolio "what's live vs simulated" panel makes the whole demo's honesty
auditable at a glance. Counter-intuitively this raises trust in what IS live.
