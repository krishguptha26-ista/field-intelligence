# ADR-008: Why build vs buy a field-audit tool
Status: position

MeazureUp, Zenput/Crunchtime, FranConnect, SafetyCulture, GoAudits, Jolt and
peers sell checklist scoring. This system's unit of record is governed
evidence: provenance from capture to corrective action, calibrated abstention,
customer/digital signals as bounded context, disputes and appeal trails, and a
verify-then-learn loop. Strategically, BroadPeak owning the FranAi layer keeps
cross-location operational memory — the compounding asset — inside the
portfolio rather than in a vendor's moat.
